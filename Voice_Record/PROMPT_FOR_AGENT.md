## Смысл (не путать)

**Голосовой пульт**, не только диктовка:

1. **Ручки (слой B):** сказал «открой хром» / «открой курсор» / «открой браузер» → запускается приложение (словарь фраз → команда). Без LLM.
2. **Диктовка (слой A):** фраза не команда (или режим «в чат») → текст в активное окно + Enter (чат Cursor; юзер сам кликнул в поле).

Hold-to-talk. Не TTS / не `Cursor_TTS`. Не IDEA-001 агент. Не mute / YouTube «заодно».

Если пользователь в стартовом сообщении не уточнил — **сначала слой B (ручки)**, потом A; или оба в одном MVP, если реально узко.

## Задача MVP

1. **Hold-to-talk** (глобальный хоткей): зажал = микрофон, отпустил = стоп.
2. Wav в `Voice_Record/recordings/` (чистить старые ок).
3. **STT** → строка (предпочтительно локальный `faster-whisper` или то, что уже взлетало у юзера на Windows; зафиксируй в README). Не always-on listening.
4. **Словарь команд** в json (5–10 шт.): нормализованная фраза → `shell`/`path`. Алиасы: браузер = chrome.
5. Матч команды → выполнить; **не** слать в чат.
6. Не матч → опционально слой A: Ctrl+V + Enter в активное окно (если в MVP включили A).
7. Пустой/короткий звук → noop. Хоткей отмены.
8. README: хоткеи, как добавить ручку, ограничения STT (шум / чужой голос = не фильтруем спикера).
