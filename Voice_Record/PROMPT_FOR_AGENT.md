## Смысл (не путать)

Пользователь хочет **говорить в микрофон и чтобы это уходило сообщением в чат Cursor**, как будто он набрал текст и нажал Enter.

Пример UX:
1. ЛКМ кликнул в поле ввода **этого** чата Cursor (фокус уже в инпуте).
2. Зажал хоткей hold-to-talk, сказал например «ты говно».
3. Отпустил → распознанный текст вставился в поле → **отправился** (Enter).

Это **вход** (voice → message). Не TTS / не `Cursor_TTS` / не озвучка ответов. Не считать, что «такое уже есть» в панели TTS.

Один фокус. Не пилить IDEA-001 агента, mute, YouTube, TTS «заодно».

## Задача MVP

1. **Hold-to-talk** (глобальный хоткей): зажал = пишем с микрофона, отпустил = стоп.
2. Сохранить короткий wav в `Voice_Record/recordings/` (можно чистить старые).
3. **STT** → одна строка текста (выбери простой стек под Windows: локальный Whisper / `faster-whisper` / Windows Speech Runtime — что реально взлетит без ада установки; зафиксируй выбор в README).
4. Текст → **активное окно**: вставка (Ctrl+V через буфер) + **Enter** (отправка).
5. MVP-допущение: пользователь **сам** кликнул в чат Cursor перед записью. Не обязателен автопоиск UI Cursor в первом прогоне.
6. Хоткей отмены (если запись залипла) + защита: пустой/слишком короткий звук не слать.
7. README: хоткеи, зависимости, как проверить на чате Cursor.
