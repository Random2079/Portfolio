## Цель

Озвучивать ответы агента Cursor локально/облачно: стабильно, без сюрпризов на Stop / Авто / прогреве модели.

## MVP / слои

| Слой | Суть | Статус |
|------|------|--------|
| Hook + панель + демон | авто после ответа, ручное, хоткеи | ✅ |
| Edge TTS | быстрый онлайн без ключа | ✅ |
| Silero | офлайн запас | ✅ |
| TeraTTS | дефолт, качество, локальный ONNX + темп | ✅ |
| Qwen / OpenAI | опционально в комбо | 🟡 |
| Kokoro | выкинут из UI/движков | ✅ убран |

## Не делаем

- Клон голоса / свой timbre «как студия»
- OpenAI как обязательный дефолт (дорого / гео)
- Возврат Kokoro в панель без отдельного решения
- 100% coverage UI и «как звучит» автотестами
- Обещание «тесты = багов не будет»

## Готово когда

- [x] Один hook-конфиг (user-level), без двойной озвучки
- [x] Авто OFF не убивает демон на warmup Tera/Edge/Silero
- [x] Stop не срывает warmup Tera (kill процесса только для Qwen)
- [x] Tera в панели + `tera_duration_scale` (темп)
- [ ] Регрессионные unit-тесты на контракт Stop/warmup/Авто (см. ниже)
- [ ] Pin `revision` для Tera `trust_remote_code` (безопасность)

## Архитектура (стыки — тут баги)

```
хук (afterAgentResponse)     панель / AHK
        │                          │
        ▼                          ▼
   speak_edge.py  ←── --stop / --warmup / speak file
        │
        ▼
   tts_daemon.py  (warmup + очередь + synth)
        │
        ├── speak_tera.py / speak_edge_tts / speak_local / …
```

**Разные смыслы «Стоп»:**

| Кто | Что должен делать |
|-----|-------------------|
| Панель «Авто OFF» | `TTS_OFF` + снять речь/очередь; **демон и warmup живы** |
| Панель/AHK Стоп | очередь + звук; warmup Tera/Edge/Silero **не** убивать |
| `speak_edge --stop` | то же; `stop_daemon(force)` **только** если `warming` и engine=`qwen` |
| Демон `cmd=stop` | clear queue + stop playback; process exit только Qwen warmup |

Ломать этот контракт = баг класса «выключил авто → модель не грузится».

## Регрессия / тесты (обязательный блок)

### Зачем в ТЗ

Не «эталон программирования» и не антибаг-магия.  
Фиксируем **контракты на стыках**, чтобы не ловить один и тот же баг после каждого «маленького фикса».

### Что тестируем обязательно (unit, без GPU/голоса)

При любом изменении Stop / warmup / Авто / `speak_edge.py --stop` / очереди — прогнать:

```powershell
cd Cursor_TTS
python -m unittest test_tts_playback.py test_text_prep.py -v
# после добавления — файл с контрактами Stop/warmup (имя уточнить при написании)
```

**Контракты (минимум):**

1. `--stop` при `warming=true`, `engine=tera|edge|local` → **не** вызывать `stop_daemon`.
2. `--stop` при `warming=true`, `engine=qwen` → **force** kill демона допустим.
3. `preview_allowed` / кнопка Прослушать при `warming=true` → запрещено.
4. Демон: Stop при warmup Tera **не** делает soft-cancel флага так, чтобы клиент решил «пора убить процесс» (keep warmup).
5. (Желательно) hook: повторный `generation_id` → skip.

### Что не гоняем автотестами

- Качество голоса Tera / Edge
- Полный cold load 30–90 с в CI
- PyQt клики «как человек»
- AHK на живой Windows (достаточно ручного сценария)

### Ручной смоук (блокер перед «готово по правке»)

1. Открыть панель → дождаться прогрева Tera (не жать Стоп).
2. **Авто OFF** во время или после прогрева → демон жив, статус не «мертвый».
3. **Прослушать** → речь за несколько секунд (если уже warm).
4. Авто ON → короткий ответ агента озвучивается один раз (без дубля).

### Политика для агента

- Меняешь Stop / warmup / Авто / `--stop` → **сначала** контрактные тесты (или напиши их, если нет), потом «пробуй».
- Не писать «покрыли всё тестами» в отчёте, если гоняли только text_prep.
- Новый движок в `_ENGINES` → в ТЗ/parts дописать: kill-on-stop? stale-timeout? нужен ли warmup keep?

## Движки (актуально)

| Engine | Роль | Cold | Примечание |
|--------|------|------|------------|
| **tera** | дефолт | 30–90 с в процесс | `duration_scale` = темп; `trust_remote_code` → pin revision |
| **edge** | быстрый онлайн | ~1–7 с | без ключа |
| **local** | Silero офлайн | после прогрева быстро | запас |
| **qwen** | качество GPU | долго | Stop на warmup → kill процесса |
| **openai** | облако | быстро | ключ + VPN; не дефолт |
