## 📖 Объяснение (как устроено)

1. **Панель** пишет `reading_profile` в `tts_config.json`, слайдеры блокирует на пресете.
2. **`reading_profiles.json`** — только цифры/подписи.
3. **Демон** на ответ: `effective_speak_settings` → pause / scale / chunk из пресета или слайдеров (manual).
4. **`text_prep.py`** → пути, `%`, `$`, словарь → нарезка → **prefetch** N+1 (не Qwen).
5. Громкость/пауза — live из конфига; темп запекается в wav → lock на время речи.

### Голоса Tera

| В панели (RU) | В модели, не в UI |
|---------------|-------------------|
| `ru_f1`, `ru_f2`, `ru_m1`, `ru_m5` | `eng_f3`, `eng_f4_whisper`, `eng_f5`, `eng_m2_whisper`, `eng_m3`, `eng_m4` |

Рекомендованные RU у авторов: `ru_f1`, `ru_m5`. EN для русского текста — 🚫 без явной просьбы.

### Фризы при загрузке / прогоне

- Tera: `CPUExecutionProvider`, `threads ≈ cpu/2` → UI Windows/Cursor делит ядра.
- Cold load 30–90 с — норма; полностью «тихо» на CPU не обещать.
- Смягчение без смены голоса (⏸ не делаем, пока не попросят): меньше `threads` / priority Below Normal у демона.
- Доп. ОЗУ поможет только если был своп; сами фризы синтеза — в основном CPU.

## 🚫 Запреты

- Не возвращать `dict_and_en` / `<en>`-переключение тембра без просьбы.
- Не коммитить: `.env`, `tts_config.json`, `TTS_OFF`, `TTS_PAUSED`, pid, логи, `_bench_*`.
- Не путать этот репо с копией в `Portfolio/Cursor_TTS` (копия может отставать).
- Панель после правок пресетов — **рестарт** (`Start_TTS_Panel.bat`); старый `pythonw` в памяти не подхватит UI.
