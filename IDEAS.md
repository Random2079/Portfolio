Общая база идей для `DS_Projects`. ИИ сверяется с этим файлом и обновляет его по просьбе («добавь в памятку», «отметь сделанным» и т.п.). Не удалять и не менять смысл идей без подтверждения.



Планы «как делать» (MVP-шаги): папка [`.cursor/plans/`](.cursor/plans/) — оглавление в [`памятка-идей.md`](.cursor/plans/памятка-идей.md).



## Правило для агентов (обновлено 2026-08-25)



- **Предпочтение, не запрет:** в **одном чате** — один трек (не мешать Translator + mute + новостник в одном диалоге «заодно»).

- **Параллель ок:** пользователь часто держит **2+ чата** — пока один агент копает A, во втором уже промпт по B. Не орáть «стоп, только один проект в жизни»; не стартовать сам третий/четвёртый без явной команды.

- **Живые коды (ориентир):** YouTube_Translator · IDEA-003 `Portfolio_News/` · IDEA-005 `Discord_VoiceMute/` · IDEA-002 TTS жить. Точный статус карточек — ниже по файлу.

- **Не начинать без команды:** IDEA-001 агент, 014 VPN, 017 Voice_Record, 018 toast, 019 Discord TTS→mic, 021 файлы dist, и прочая парковка во входящих. IDEA-022 overlay — MVP уже в `YouTube_Translator/overlay_player.py` (допил только по запросу).

- Новый ID — если сказали «делаем IDEA-0XX» / назвали проект. Сомневаешься — сверка с этим файлом, не пилить молча.

### IDEA-001 — AI-агент с TTS-озвучкой

- Проект/область: новый / голосовой агент

- Дата: 2026-07-18

- Статус: входящие

- Описание: Сделать ИИ-агента с TTS-озвучкой в духе Neuro-sama или похожее. Кандидаты голоса: **IndexTTS2**, **Qwen3-TTS** (клон / эмоции / design) — см. заметки у IDEA-002. Архитектура «свой ассистент»: **мозг** (LLM) + **ручки** (tools) + **карта контекста** (где что лежит: IDEAS, MAP, portfolio CSV, dist, правила) — агент знает маршруты к знаниям, не обязан тащить весь мир в каждый промпт.

- Доп. (2026-09-21) — **Jev (TypeSafe System One) для экономии токенов на простых задачах:**
  - Jev = не чат и не замена мозгу: только быстрые решения (да/нет, выбор из меню, score).
  - Перед дорогим LLM: triage (болтовня / напоминание / файл / код / инвест / оффтоп) → trivial без LLM; simple → дешёвая модель; hard → полный мозг + нужные ручки.
  - Выбор 0–2 skills / источников из меню («куда смотреть»), чтобы не грузить весь контекст и все skills в каждый запрос.
  - Роутинг модели (Haiku vs Sonnet/Opus) по типу задачи.
  - Низкий confidence → эскалация на мозг; иначе шаблон/скрипт/дешёвый tier.
  - Доступ: TypeSafe API или OpenRouter Decisions API (`typesafe/jev-1.13`); в Cursor — скорее MCP/свой слой ассистента, не model picker.
  - Цены (сверка): ~$0.042/1M input, output free — дёшево как сторож, не как генератор текста.

- Следующие шаги: уточнить стек (локальный/облачный TTS, LLM, UI). План: [`.cursor/plans/IDEA-001-agent-mvp-roadmap.md`](.cursor/plans/IDEA-001-agent-mvp-roadmap.md). Не начинать, пока не разгребём TTS/mute по очереди. В roadmap учесть слой Jev (роутер) рядом с мозгом — когда дойдём до чат-цикла.
