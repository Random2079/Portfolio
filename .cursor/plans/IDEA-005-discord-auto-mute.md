# IDEA-005 — Discord VoiceMute (продукт)

## Цель продукта

Утилита для Discord: знает **кто ты** и **в каком лобби**, список **чужих**, по команде мьютит нужного человека.  
Запуск **без консоли** — `DiscordVoiceMute.exe` (трей / маленькое окно).  
Сложность: средняя. Код: аккуратный, модульный, как маленький продукт, не одноразовый скрипт.

Не mute себя по дБ. Без Discord-бота / API (пока).

## UX (как «активировать»)

1. Двойной клик по **exe** → висит в трее (или крошечное окно статуса).
2. Статус всегда виден кратко: `lobby: 12 | others: 3` / ошибка OCR.
3. Глобальный хоткей (настраиваемый, дефолт например Ctrl+Shift+M hold): зажал → сказал «замуть 3» → отпустил → действие.
4. Первичная настройка один раз: ник, ROI сайдбара, проверка «вижу лобби».
5. Консоль — только для отладки разработчика, не основной способ запуска.

## Стек (зафиксировано)

- **Язык:** Python 3.11+
- **Детект:** скрин ROI + OCR (EasyOCR или легче, если потянет качество)
- **Mute:** клики по UI Discord (после стабильного детекта)
- **STT:** позже (Whisper / Windows) на hold-to-talk
- **Сборка:** PyInstaller → один exe (+ рядом `config.json`, модели)
- **Не AHK как ядро.** AHK опционально никогда не обязателен; хоткеи — из Python (`pynput` / аналог)

## Захват Discord (зафиксировано — просто)

- Дефолт **`capture_mode: game`**: только PrintWindow, **без** restore/topmost.
- Discord открыт на **текущем** рабочем столе, можно под другими окнами. Не сворачивать, не уносить на другой вирт. стол.
- Не смогли снять → `discord_unavailable` / `capture_failed`, игру не трогаем.
- `normal` — только для отладки (restore разрешён).
- Виртуальные столы / бот / невидимый Discord — **не в scope** пока.

## Решения по домену

- **Я** = `Ищу работу (Python Dev)` в конфиге (+ aliases).
- **Лобби** = голосовой канал над ником в сайдбаре.
- **Чужие** = остальные в этом канале.
- **Слот N** = N-й чужой сверху вниз в текущем лобби.
- Старое «дБ → mute себя» — не делаем.

## Качество кода (планка)

- Модули: `config`, `capture`, `ocr`, `parse_lobby`, `mute_click`, `hotkeys`, `app` (tray/UI).
- Типы, понятные имена, без бога в одном файле.
- `config.example.json` + README: установка, калибровка, сборка exe.
- Логи в файл (рядом с exe), не только print.
- Ошибки OCR/не найден ник — статус в UI, не молчаливый краш.
- Тесты на парсер лобби (без OCR).

## Не в scope

- Красивый «дизайнерский» UI / дашборд
- Discord-бот, Mute Members API
- Mute по нику голосом («замуть Васю») — после MVP
- Ползунок громкости
- AHK как основной рантайм
- Виртуальные столы / невидимый Discord / сложный focus-hack

## Риски

- OCR + кириллица, масштаб Discord, скролл сайдбара
- Жирный exe из‑за OCR/torch — нормально для v1; позже можно сменить OCR-движок
- Без прав мода — только то, что есть в ПКМ Discord

## MVP по слоям

### A — глаза (сейчас в `Discord_VoiceMute/`)

Детект lobby/me/others. Можно временно из консоли. Готово, когда на живом Discord совпадает с глазами.

### B — руки

Калибровка кликов, mute/unmute слота N по команде текстом.

### C — голос + продукт

Hold-to-talk STT, трей-окно, статус, **сборка exe**, автозапуск опционально.

## Готово когда (продукт)

- [ ] A стабилен на твоём Discord
- [ ] B мьютит нужного чужого
- [ ] Exe запускается двойным кликом, висит в трее, хоткей работает без открытия терминала
- [ ] README: калибровка + `build_exe` инструкция
