# IDEA-011 — Субтитры с таймкодами (не каждое слово)

## Цель

Текст с привязкой ко времени (фразы / куски), чтобы сопоставить момент с картинкой в ролике. Не word-level на каждую секунду.

## Статус: готово (2026-08-06)

## Сделано

- Формат: `1_текст_с_таймкодами.txt` — строки `[mm:ss] фраза`.
- Склейка: пауза &lt; 1.5 с, длина ≲ 120 символов; резать по `.?!…` если раздулось.
- `0_весь_текст_для_буфера.txt` + Ctrl+V — чистый текст без изменений.
- README обновлён; exe пересобран.
