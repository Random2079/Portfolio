# IDEA-016 — Локальный плеер таймкодов

## Цель

После прогона ролика в `YouTube_Translator` открыть **один** `player.html`: слева/сверху YouTube iframe, справа/снизу кнопки. Клик сикает плеер в том же окне (не новая вкладка Chrome).

Не платформа, не расширение VS Code, не аккаунты. Видео не скачивать.

## Зачем

`1_текст_с_таймкодами.txt` уже есть (IDEA-011). Сейчас `youtu.be?t=` каждый раз открывает браузер заново.

## MVP

1. Генерировать `player.html` в папке ролика рядом с таймкодами: `dist/субтитры_<title> [<youtubeId>]/`.
2. YouTube id — из имени папки `[...]`.
3. Клик → YouTube IFrame API `seekTo`, без новой вкладки.
4. Кнопки из `1_текст_с_таймкодами.txt` — проредить (шаг ~20–30 сек или склейка), не сотни кнопок.
5. Опционально `метки.txt` или `highlights.json` вида `mm:ss | заголовок` — эти кнопки сверху как «полезные».
6. Вшить в `Subtitle_App.py`: после записи таймкодов писать `player.html`. Кнопка в GUI «открыть файл» — ок; автозапуск браузера не обязателен.
7. Один HTML+JS, без npm и без сервера. Если API на `file://` не взлетит — минимальный `http.server` или пометка в README.

## Ограничения

- Windows, Python как сейчас.
- GUI и формат папок не ломать.
- Код простой, можно показать в GitHub.

## Не в scope

- Скачивание видео
- Расширение VS Code / облако / аккаунты
- Красивый дашборд

## Готово когда

Прогнал ссылку → в папке есть `player.html` → открыл → жму метку → прыгает в том же окне.
