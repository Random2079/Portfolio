# IDEA-017 — Голосовой пульт (ручки + диктовка в Cursor)

## Цель

Hold-to-talk → распознанный текст →:

1. **Ручка:** фраза из словаря → действие ОС (`открой хром` / `открой курсор` / …).
2. **Диктовка:** иначе (или отдельный режим) → вставка в активное окно + Enter (чат Cursor).

Вход к IDEA-001, не TTS (выход). Не SS14 (012).

## UX

1. Глобальный hold-to-talk: зажал = запись, отпустил = STT.
2. Если текст матчит команду → выполнить, **не** слать в чат.
3. Если не команда и фокус в чате Cursor → Ctrl+V + Enter.
4. Короткий/пустой звук → ничего не делать. Отмена хоткеем.

## MVP (узкий)

**Слой B (ручки) — удобный старт «видно сразу»:**
- 5–10 команд в конфиге (json): фраза → путь/shell.
- `chrome`, `cursor`, `браузер` = алиасы.
- Без LLM: точный/простой fuzzy match.

**Слой A (диктовка) — рядом или вторым прогоном:**
- Буфер + Enter в сфокусированное поле (юзер сам кликнул в чат).

Общий фундамент: запись wav + STT + хоткей.

## STT — реалистичные ожидания

| Вопрос | Ответ |
|--------|--------|
| Это нейронка? | Обычно да: Whisper-класс (`faster-whisper`) или облако/Windows Speech. Не «магия отдельного продукта». |
| Хорошо ли? | На коротких командах при нормальном мике — ок. Длинная диктовка — хуже; русский у small/base норм для команд. |
| Шум сзади | Точность падает. Hold-to-talk (не always-on) + RTX Voice / хороший мик. VAD опционально позже. |
| Чужой голос | STT **не** знает «это не хозяин» — распознает речь кто угодно в клипе. Speaker ID — не MVP. |
| Always listening | Не в MVP (батарея/ложные срабатывания/приватность). |

Ориентир стека: то, что уже знакомо с Discord Mute STT; зафиксировать выбор в README при старте кода.
