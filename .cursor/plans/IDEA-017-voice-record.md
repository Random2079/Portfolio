# IDEA-017 — Голос → сообщение в чат Cursor

## Цель

Сказал в микрофон → в **чат Cursor** ушло текстовое сообщение (Send), без ручного набора.

Пример: ЛКМ в поле ввода чата → «ты говно» голосом → в ленте чата то же текстом.

Это **вход** к агенту (связь с IDEA-001), не TTS (выход).

## UX (как сказал пользователь)

1. Фокус в чат Cursor (клик ЛКМ в поле ввода).
2. Хоткей hold-to-talk (или start/stop): говоришь.
3. Отпустил → STT → текст в поле → **отправка** (как Enter).

## MVP

1. Запись с микрофона (wav во временный файл ок).
2. STT → строка текста (Windows Speech / Whisper / API — выбрать простой).
3. Вставка в активное окно (буфер + Ctrl+V) и Enter.
4. Предпосылка MVP: пользователь сам кликнул в чат (фокус уже там). Автопоиск окна Cursor — опционально позже.
5. Стоп/отмена хоткеем.
