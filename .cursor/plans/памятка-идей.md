## Треки (обновлено 2026-08-25)



Раньше (2026-08-08): жёстко «один фокус — мозг взрывается».  

**Сейчас:** пользователь **не соблюдает** жёсткий один-фокус и не хочет его как запрет.



Правила для агентов:



1. **Предпочтение:** в одном чате — один трек (не мешать проекты «заодно» в одном диалоге).

2. **Параллель ок:** 2 чата = 2 трека потихоньку нормально. Не запрещать вторую ветку жизни; не тащить сам третий/четвёртый без команды.

3. **Ориентир живого:** YouTube_Translator · IDEA-003 · IDEA-005. IDEA-002 TTS + IDEA-013 — **готово / жить**. IDEA-015 отклонена.

4. Новый код по парковке (001, 014, 017…) — только «делаем IDEA-0XX» / явное имя проекта.

5. Сомневаешься — сверка с `IDEAS.md`, не пилить.
