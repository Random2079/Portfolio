# IDEA-003 — Новостник портфеля

## Цель

Список тикеров → периодический сбор новостей → пуш в один канал (сначала Telegram или toast на Windows). Без тяжёлого UI на старте.

## Зачем

Не сидеть в терминале/браузере вручную. Короткий дайджест «что вышло по моим бумагам».

## Железо / стек (MVP)

- Windows, Python 3.12+
- Папка проекта: `Portfolio_News/` (новая)
- Конфиг: `tickers.json` + `.env.example` (токены не в git)
- Источники новостей: начать с бесплатных/простых (RSS / публичные API), без платного Bloomberg
- Уведомления MVP: **Telegram bot** (один chat_id) **или** Windows toast — выбрать одно в первой итерации
- UI «веб/React» — **не** в MVP; позже, если живой CLI/daemon зайдёт

## MVP (один фокус)

1. `tickers.json`: `["SBER", "GAZP", …]` + опционально рынок (MOEX / US).
2. Скрипт/демон: раз в N минут (конфиг) тянет новости по тикерам.
3. Дедуп: не слать одну и ту же ссылку/заголовок повторно (`seen.json` / sqlite).
4. Сообщение: тикер · заголовок · ссылка · источник · время.
5. README: установка, `.env`, запуск, как добавить тикер.
6. Без аккаунтов брокера, без автоторговли, без «ИИ советует купить».

## Не в scope (пока)

- React дашборд
- Инвест-советы / сигналы на вход
- Смешение с воркспейсом `Инвестиции/` (чеклисты портфеля) — это **код-утилита**, не финконсультант
- Парсинг платных терминалов

## Готово когда

Добавил 2–3 тикера → запустил → при новой новости пришло уведомление → повтор той же новости не пришёл.
