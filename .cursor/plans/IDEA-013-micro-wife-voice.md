# IDEA-013 — Micro wife (свой женский голос)

## Цель

Нормальный **женский** голос для Cursor TTS. Piper-Ирина не зашла. Рабочее имя: **micro wife** — клон или voice design, не «ещё один onnx из списка».

## Железо

i5-12450H / 16 GB / **RTX 3050 4 GB** → начинать с **Qwen3-TTS 0.6B** (~&lt;2 GB VRAM). IndexTTS2 — запасной, тяжелее.

## Не в scope (пока)

- Ломать рабочий Edge / Silero / Piper  
- Полный Neuro-агент (это IDEA-001)  
- Стрим озвучки пока Agent пишет  

## Порядок (маленькими шагами)

```mermaid
flowchart LR
  pick[1_выбрать_движок]
  sample[2_образец_или_design]
  proto[3_прототип_вне_демона]
  wire[4_опционально_в_панель]
  pick --> sample --> proto --> wire
```

### 1 — Выбор движка
- По умолчанию: **Qwen3-TTS 0.6B**  
- Альтернатива: IndexTTS2, если нужен сильнее эмоции/клон  

### 2 — Откуда голос
- **A:** 5–10 сек чистого образца (свой / легальный) → клон  
- **B:** текстовый voice design («мягкий женский русский…») без образца  

### 3 — Прототип
- Скрипт вне `tts_daemon`: текст → wav → play  
- Замер latency vs Piper/Silero  
- Голос «ок на слух» → идём дальше; нет — крутим design/образец, не пихаем в панель  

### 4 — Врезка (только если 3 ок)
- Отдельный `engine` в конфиге (не ломая piper/edge/local)  
- Пункт в панели + README «как положить образец / модель»  

## Готово когда

В панели можно выбрать micro wife; фраза звучит как «свой» женский голос, не Ирина-пластилин. Latency приемлема для длинных ответов (можно медленнее Piper).
