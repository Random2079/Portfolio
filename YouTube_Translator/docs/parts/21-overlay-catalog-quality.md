## Цель (канон)

1. **🎞↓** качает **максимально доступное** качество видео (+ mp3 best).  
2. В Фоне видно не «сырой проводник», а **карточки треков**: превью + название + что есть пара (mp4 / mp3).  
3. Порядок списка: **от старого к новому** (дата файла).  
4. Потом: **удалить** пару с диска + **переименовать** файлы (отображаемое имя = имя на диске).  
5. Позже: **случайный** трек / shuffle.

## Чанки (лестница)

### C0 — Качество 🎞↓ → max ✅

**Сделано**
- `-f bestvideo*[height<=2160]+bestaudio/bestvideo*+bestaudio/best` + `-S res,fps,vbr,abr`
- DASH fallback с тем же max
- После качки: статус / return с `WxH · filename` (ffprobe)
- Тест: `test_overlay_download.py`; смоук Alan Walker Faded → **1920x1080**

---

### C1 — Порядок: дата старый → новый ✅

**Сделано**
- `scan_media(..., sort=)` — `date_asc` (канон) / `date_desc` / `name`
- Prefs `catalog_sort` (дефолт `date_asc`); `_reload_list` читает prefs
- Тест: `test_scan_media_sort.py` (mtime + dedupe)

---

### C2 — Каталог: карточки пары + превью + название ✅

**Сделано**
- `CatalogCardWidget`: название + бейджи `mp4`/`mp3` + превью
- `catalog_entry_meta` — флаги пары; клик/play как раньше (`UserRole` = path)
- Thumbs: ffmpeg → `%LOCALAPPDATA%\.subtitle_ripper\thumbs\<id>.jpg`, очередь в фоне
- Тесты: `test_catalog_cards.py`; смоук thumb на реальном mp4

**Не в C2:** delete, rename, теги, поиск, drag-drop, «открыть в проводнике».

---

### C2b — Удалить + переименовать (диск) ⬜ **СТАРТ**

**Канон решения пользователя (2026-10-02)**  
1A удалить **файлы с диска** (mp4 и/или mp3 пары) · 2A смотреть = превью+play (уже C2) · 3A rename = **отображаемое имя и файлы на диске** · 4A постепенно после C2.

**Делаем**
- **Delete:** подтверждение → удалить файлы пары (оба ext с тем же `[id]` / stem), rescan списка; если играл этот трек — stop.
- **Rename:** диалог нового title → переименовать mp4/mp3 на диске (сохранить `[youtubeId]` в имени, если был); обновить список / текущий play path.
- Контекстное меню или кнопки на карточке (минимально).

**Не в C2b:** bulk multi-select, корзина/undo, теги, 021 F1 для `dist/` (это другой слой).

**Смоук:** rename пары → оба файла с новым stem; delete → файлов нет, карточки нет.
