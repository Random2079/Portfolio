## Цель (канон)

1. **🎞↓** качает **максимально доступное** качество видео (+ mp3 best).  
2. В Фоне видно не «сырой проводник», а **карточки треков**: превью + название + что есть пара (mp4 / mp3).  
3. Порядок списка: **от старого к новому** (дата файла).  
4. Позже: **случайный** трек / shuffle.

---

## Факт сейчас (аудит)

| Что | Как в коде | Заметка |
|-----|------------|---------|
| mp4 fmt | `bv*+ba/b` (`_OVERLAY_FMT_DEFAULT`) | «лучшее видео+аудио», но без явного `height` / `vcodec` preference; merge → mp4 |
| mp4 fallback | `299+140/298+140/137+140/bestvideo*+bestaudio/best` | 1080p60 / 1080p / 1080p — ок как retry |
| mp3 | `-x --audio-format mp3 --audio-quality 0` | уже max VBR |
| Список | `scan_media` → **алфавит** `name.lower()` | не по дате |
| Дубли | один `[youtubeId]` → предпочитает **видео** | пара mp3+mp4 схлопывается в одну строку (играет mp4) |
| UI списка | `QListWidget` текст | без превью, без явной метки «есть mp3» |
| Папка | `QFileDialog` «как проводник» | неудобно ориентироваться |

`bv*+ba` обычно даёт max, но на части роликов yt-dlp может взять не тот стрим. Цель C0 — **явно max** + смоук/лог фактического format.

## Чанки (лестница)

### C0 — Качество 🎞↓ → max ✅

**Сделано**
- `-f bestvideo*[height<=2160]+bestaudio/bestvideo*+bestaudio/best` + `-S res,fps,vbr,abr`
- DASH fallback с тем же max
- После качки: статус / return с `WxH · filename` (ffprobe)
- Тест: `test_overlay_download.py`; смоук Alan Walker Faded → **1920x1080**

**Не делаем:** UI каталога, сортировка.

---

### C1 — Порядок: дата старый → новый ✅

**Сделано**
- `scan_media(..., sort=)` — `date_asc` (канон) / `date_desc` / `name`
- Prefs `catalog_sort` (дефолт `date_asc`); `_reload_list` читает prefs
- Тест: `test_scan_media_sort.py` (mtime + dedupe)

---

### C2 — Каталог: карточки пары + превью + название ⬜ **СТАРТ**

**Зачем:** не «проводник», а медиатека Фона.

**UI (минимум)**
- Список/грид: **одна карточка = один YouTube id / stem**.
- Показать: **название** (stem без `[id]`), бейджи `mp4` / `mp3` (что реально на диске).
- **Превью:** кадр из mp4 (cached thumb рядом или в `%LOCALAPPDATA%` / `.subtitle_ripper/thumbs/`) или иконка-заглушка для audio-only.
- Клик по карточке = как сейчас play (с учётом sibling mp4).

**Папка…**
- Диалог выбора папки оставить, но вторично; дефолт `Music\YouTube_DL` без обязательного «лайв проводник».
- Не строить полный Explorer-клон.

**Не в C2:** теги, поиск, drag-drop плейлистов.

**Смоук:** видно пару mp4+mp3 на одной карточке; превью у mp4; клик играет.

## Зависимости чанков

```
C0 (качество) ── независим
C1 (дата)     ── независим, дёшево
C2 (карточки) ── опирается на dedupe C0/C1; thumbs нужен mp4
C3 (random)   ── после C1
```

Рекомендуемый порядок внедрения: **C0 → C1 → C2 → C3**.
