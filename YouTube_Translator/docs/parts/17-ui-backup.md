# Part 17 — UI backup / запас интерфейса

Карточка TZ **№19**. Зачем: после длинного polish overlay (клики, хоткеи, opacity, fullscreen) пришлось **заново настраивать всю логику UI** — это недопустимо. Нужны запасные копии и правила «не ломать вслепую».

Команда: `делаем part 17` / перед крупным UI-фиксом — «бэкап UI».

---

## Боль (слова пользователя)

> Делать backup или запасные, чтоб такой хуйни не было — что пришлось настраивать всю логику интерфейса заново. Это пиздец.

---

## Правило (жёстко)

1. **Перед** крупным рефактором / переписыванием поведения UI (overlay, хоткеи, клики, stage/catalog, prefs):
   - скопировать рабочие файлы в `backups/ui/` с датой в имени;
   - не начинать «с нуля», пока нет копии «как сейчас работает».
2. **Запрещено** без явной просьбы: выкинуть и заново написать `overlay_player.py` / весь layout / всю карту хоткеев.
3. Чинить **точечно** по симптомам; откат = вернуть файл из `backups/ui/`, не угадывать заново.
4. Контракт UX (ниже) — источник правды; агент сверяется с ним и с part 12/16, а не «улучшает» молча.

## Что бэкапить

| Артефакт | Куда |
|----------|------|
| `overlay_player.py` | `backups/ui/overlay_player_YYYY-MM-DD_<метка>.py` |
| `Subtitle_App.py` (если трогаем проводку 🎞 Фон / окна) | `backups/ui/Subtitle_App_YYYY-MM-DD_<метка>.py` |
| prefs (опционально) | копия `~/.subtitle_ripper/overlay_prefs.json` → `backups/ui/overlay_prefs_YYYY-MM-DD.json` |

Папка `backups/ui/` в репо (или рядом с проектом). Не коммитить секреты; prefs без токенов — ок.

**Метка** — коротко: `working`, `pre-hotkeys`, `pre-clicks` и т.п.

## Контракт UX overlay (не терять)

Зафиксировано боем 2026-09-08; менять только по явному запросу.

| Поведение | Как должно |
|-----------|------------|
| 1-й клик по треку | Play **в каталоге**, без fullscreen (если «Превью» вкл) |
| 2-й клик по тому же | Fullscreen / stage, **без рестарта** трека |
| «Превью» выкл | Клик только выбирает; play — ▶ |
| Stage / fullscreen | **Плотность** со слайдера всегда (и без сквозь); каталог скрыт |
| Каталог | Всегда непрозрачный (100%) |
| Клик по видео в stage (не сквозь) | Pause / play |
| Space | Play/pause (в фокусе окна) |
| Ctrl+Shift+F1 | Play/pause **глобально** |
| Ctrl+Shift+1 / 2 | След / пред (глобально, приоритет над AIMP) |
| Ctrl+O / Ctrl+Shift+O | Сквозь / скрыть (глобально) |
| Esc | 1) выкл сквозь + панель; 2) из fullscreen → каталог (глобально в stage/сквозь) |
| ☰ Каталог | Внизу (не сверху); назад к списку, музыка не стопается |
| Ctrl+O | Сквозь + **скрыть нижнюю панель**; только хоткеи; opacity не в 100%; если было >70% → ~40% |
| Z-order | Always-on-top (поверх Chrome/окон; exclusive fullscreen игр — ограничение Windows) |
| Esc | **Не** кидает в каталог |
| Папка… | Диалог с фильтром Медиа/Видео/Аудио; папка = родитель выбранного файла |

Prefs: `~/.subtitle_ripper/overlay_prefs.json` (`stage_opacity`, `play_when_hidden`, `catalog_preview`, `hotkeys`).
