## Цель (канон продукта)

Анимация Фона играет **поверх чего угодно** (игра, обои, Cursor, браузер).  
Система **сама** ставит плотность (% opacity при сквозь) так, чтобы анимацию было **комфортно видно**: не «в ноль» на светлом и не «орёт» на тёмном.

- Не обязательно realtime каждый кадр — достаточно, чтобы **глаз не дёргался** и результат был ок после короткого теста.
- Оптимум базы / интервала / кривой — **подбираем тестом** (prefs), не угадываем идеал в коде.
- Светлый фон под стеклом → **плотнее**. Тёмный → **прозрачнее**.

## Жёсткие ограничения (не ломать)

| # | Правило |
|---|---------|
| 1 | `% < 100` только при сквозь (`_apply_stage_opacity`). |
| 2 | Пока сквозь + topmost — **не** `QScreen.grabWindow` / hide окна: вспышка поверх чужого приложения. |
| 3 | Авто-% **не** писать в `stage_opacity` prefs (A2). |
| 4 | Next track / Stopped не срывать авто-стекло вспышкой 100% (A2). |
| 5 | Ctrl+[ / ] — ручной override, авто не перебивает сразу (~пауза). |
| 6 | Не ронять процесс, не второй экземпляр из‑за hide (сворот в панель). |
| 7 | Нагрузка: тик захвата/расчёта — ориентир **≪ 5% одного ядра** в среднем; без утечки RAM кадрами. |

Узкое место всегда **захват экрана**, не «среднее по кубикам».

## План сложности (снизу вверх)

Идём **снизу**. Следующий слой — только если после смоука «мало / не то».

### B0 — Комфорт на том, что уже работает ⬜ **СТАРТ**

**Идея:** не новый захват. Сделать поведение глазу спокойным и предсказуемым.

| Делаем | Не делаем |
|--------|-----------|
| Плавный **lerp** opacity к целевому % (не скачок) | DXGI / dxcam |
| Дефолт adapt **3 с** (не 1 с); настройка в Настр. | Сэмпл «под» игру каждый тик |
| При CT: только **обои + кэш до CT** (как сейчас) | `grabWindow` / hide при CT |
| Статус + лог с `L0.xx` и `Nms` | Отдельный процесс |
| Подкрутка кривой lo/hi по результату одного смоука | ML |

**Смоук B0:** полное окно → play → idle/Ctrl+O → сквозь; уйти в Cursor — **без вспышек**; % стабильный/плавный; лог пишется; CPU тихо.

**Критерий «хватит»:** на типичных обоях + Cursor комфортно, мигания нет. Если «на Bannerlord светлом меню анимацию не видно» → B1 или B2.

### B1 — Лучше оценка без опасного grab ⬜

Только если B0 ок по стабильности, но % «мимо».

| Варианты (дешёвые) | |
|--------------------|--|
| Кривая luma→% (p90, lo/hi, база) по тест-матрице светлый/тёмный стол | |
| Перед CT: один даунскейл-grab краёв → кэш (уже почти есть) | |
| Редкий **безопасный** пересчёт: только когда **не** CT / после Esc→снова idle | |
| Prefs: `pct_lo` / `pct_hi` или «агрессивность» для теста | |

**Не в B1:** DXGI, второй язык.

---

### B2 — Нормальный capture (если B0+B1 мало под игрой) ⬜

Когда кэш/обои принципиально не видят светлую игру под стеклом.

| Делаем | Риск |
|--------|------|
| Отдельный тонкий модуль (**dxcam** / DXGI Desktop Duplication), не `grabWindow` | Зависимость, Win-only |
| Даунскейл → сетка «кубов» → среднее/p90 → цель % | Сложнее отладка |
| Тик редкий (2–5 с) + lerp из B0 | Нужен смоук на вспышки |
| Fallback на B0 при ImportError / ошибке capture | Не ронять Фон |

**Стоп-условия B2:** вспышки на чужом окне; >~5% ядра стабильно; краши/чёрный экран → откат на B0 path.

## Модель % (для тестов)

Черновик (подкрутка в B0/B1):

- Сетка по даунскейлу (не full HD в RAM).
- Яркость зоны → **p90** светлых клеток (тёмное море не «съедает» небо).
- Map: тёмный → ~18%, светлый → ~88% (база prefs сдвигает).
- К цели идём **lerp**, не `setValue` скачком.

Юзер крутит в Настр.: база, idle до сквозь, интервал adapt — и говорит «мало/много».

## Нагрузка и отказоустойчивость

| Риск | Митигация |
|------|-----------|
| Вспышка на Cursor/игре | Запрет grab/hide при CT (B0); B2 только после проверки |
| CPU | Редкий тик + даунскейл; без хранения кадров |
| RAM | Не кэшировать QPixmap экрана — только `float` luma |
| Краш capture | try/except → обои/кэш/база; Фон жив |
| Второй экземпляр | Ctrl+Shift+O = minimize, не hide |
| Логи | `auto_density.log` (обрезка размера) — смоук без догадок |

## Смоук-чеклист следующего слоя (B0)

1. Рестарт Фона, авто-плотность вкл.  
2. Полное окно + play → idle или Ctrl+O.  
3. Уйти в другое окно на 20+ с — **нет** появления/мигания Фона поверх.  
4. Статус/лог: `%` + источник (`кэш` / `обои`) + `L…`.  
5. Смена трека — без вспышки 100%.  
6. Esc — ручная плотность из prefs.  
7. Субъективно: на светлом/тёмном столе комфортно или записать «надо плотнее/прозрачнее» → B1.
