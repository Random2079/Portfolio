## Сделано

| Что | Как |
|-----|-----|
| Вход | В **плеере** кнопка **📁** (не на экране скачивания) |
| Список | Папки `субтитры_*` |
| Файлы | `.txt` в папке (сверху `0_весь_текст…`, `1_текст_с_таймкодами…`) |
| Просмотр | Текст **внутри** диалога |
| Копировать | «Копировать всё» / выделенное |
| Проводник | Опционально «В проводнике…» |
| Prefill | Если открыт ролик — выделяется его папка |

## Плеер — размер по умолчанию
