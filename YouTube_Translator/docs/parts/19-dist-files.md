## F0 (сделано) — посмотреть как выглядит

| Что | Как |
|-----|-----|
| Вход | Кнопка **📁 dist** на экране скачивания (рядом с Фон) |
| Список | Папки `субтитры_*` из `_subtitle_search_roots()`, свежие сверху |
| Открыть | «Открыть в проводнике» / двойной клик |
| Корень | «Папка dist…» → `default_output_root()` |
| Не в scope | Музыка, удаление, rename, копирование |

**Смоук:** `python Subtitle_App.py` → 📁 dist → список → Открыть → проводник на папке.

## F1 (позже)

Удалить / переименовать выбранную папку — только после «делаем F1».
