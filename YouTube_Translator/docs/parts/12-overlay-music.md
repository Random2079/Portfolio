## 🎯 Зачем



Фон за работой: каталог локальной музыки / mp4 → окно **поверх всех**, полупрозрачное, звук + анимация; мышь может идти **насквозь** в Cursor/браузер.



Встроено в Subtitle Ripper Pro (не отдельное приложение) — как просил пользователь.



## MVP (сделано)



| Фича | Как |

|------|-----|

| Вход | Кнопка **🎞 Фон** рядом с 🎵 Музыка на экране скачивания |

| Каталог | По умолчанию `~/Music/YouTube_DL`; кнопка «Папка…» |

| Список | Локальные mp3/m4a/wav/flac/ogg + mp4/webm/mkv/… |

| Play | `QMediaPlayer`; mp4 → видео; audio → эквалайзер-визуал; **audio сбрасывает `setVideoOutput(None)`** (иначе mp3 часто молчит) |

| Sibling | `track.mp3` + `track.mp4` рядом → играет mp4 |

| Громкость | Слайдер 🔊 0–100% (`QAudioOutput.setVolume`) |

| Always on top | `WindowStaysOnTopHint` |

| Opacity | Слайдер 20–100% |

| Click-through | Только хоткей (галка убрана) — Win32 `WS_EX_TRANSPARENT` |

| Хоткей | **Ctrl+Shift+O** — показать если скрыто, иначе вкл/выкл сквозь |



Standalone: `python overlay_player.py`



## 🔍 Проверка



1. `python Subtitle_App.py` → **🎞 Фон** → список из Music\YouTube_DL.  

2. Клик по mp3/mp4 → звук + картинка/визуал.  

3. Opacity вниз → видно окна под ним.  

4. «Клики насквозь» → клики уходят в приложение снизу; **Ctrl+Shift+O** возвращает управление.  

5. Скачивание субов / плеер / 🎵 не ломаются.



## ⚠️ Риски / gaps



- Нужен **PySide6 QtMultimedia** (видео/аудио кодеки ОС). Без него окно откроется с предупреждением, play мёртв.  

- Click-through только Windows.  

- Хоткей может быть занят другой программой.  

- Плоский скан папки (без рекурсии) — MVP.  

- IDEA-021 (файловый менеджер dist) — **не** трогали, парковка.
