# DeepSeek_IA

Черновой CLI-скрипт для запросов к **DeepSeek API** через OpenAI-совместимый клиент.

## Статус

- `В разработке / эксперимент`.
- Это не production-утилита и не основной проект портфолио.
- В репо нет публичного smoke-test (нужен личный API-ключ).

## Настройка

В корне `DS_Projects` файл `.env` (не в git):

```
DEEPSEEK_API_KEY=твой_ключ
```

## Запуск

```powershell
pip install openai python-dotenv
python DeepSeek_IA/deepseek_python_20260527_8e582e.py
```

Скрипт интерактивный: вводишь запросы в консоли, выход — `exit` / `quit` / `выход`.

## Зависимости

- `openai`
- `python-dotenv`

## Ограничения текущей версии

- Один файл без тестов/CLI-флагов.
- Модель захардкожена в коде (`MODEL = "deepseek-v4-pro"`), может потребоваться поменять под актуальный тариф/доступ.
- Повторы реализованы простым перехватом `429/503` по тексту ошибки.
