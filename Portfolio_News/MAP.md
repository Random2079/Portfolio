## 7. План F-A (следующий код) — целиком здесь

**Зачем:** на вкладке «Новости» видеть шум vs ок, без ордеров.

**Триггер:** кнопка **«Прогнать ИИ»** по сегодняшним (scope BCS).  
Авто в poller — **не в A**.

**Модель:** DeepSeek JSON-only, паттерн как `YouTube_Translator/ai_analyze.py`.  
Ключ: `DEEPSEEK_API_KEY` только в `Portfolio_News/.env`. Флаг `ai_noise_enabled`.

### Ответ модели

| Поле | Значения |
|------|----------|
| `label` | `noise` \| `relevant` \| `dup` |
| `urgency` | `low` \| `mid` \| `high` (если relevant) |
| `reason` | коротко ≤120 |
| `model` / `as_of` | служебное |

Запрещено: купи/продавай, таргет, ордер.

### Шаги реализации

| Шаг | Что |
|-----|-----|
| **A0** | Поля AI на `news` (или `news_ai_cache` по id) |
| **A1** | `portfolio_news/ai_noise.py` + конфиг + тесты парсера без сети |
| **A2** | `POST /api/news/ai-classify` (пачка, today_only, лимит ~20–40); `/api/news` отдаёт AI-поля |
| **A3** | UI: кнопка + бейджи шум/ок/дубль + тумблер «скрыть шум» (localStorage) |
| **A4** | Смоук: с ключом бейджи есть; без ключа лента жива; pytest |

### Не в F-A

Авто-classify в poll, разбор тикера (B), чат, forecast 023, замена RSS на LLM.

### F-B и чат (кратко, потом)

- **B:** тикер + новости → JSON: на что бьёт / срочность / `checklist[]` к стратегии; панель, не пузырьки.  
- **Чат:** быстрые вопросы по данным приложения; не замена B.
