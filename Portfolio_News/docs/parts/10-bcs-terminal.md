## K9 антиспам (не ломать)

- Не пушить новости **за прошлые дни** при первом/любом опросе.
- Дефолт: **один digest** на poll, не 50 toasts.
- `notify=off` / выключатель в UI обязан глушить сразу.
- Scope = только holdings БКС.
